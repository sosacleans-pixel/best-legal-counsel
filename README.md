# Best Legal Net

English homepage: `index.html`. Spanish homepage: `es/index.html`. Private intake: `intake/` and `intake/es/`. Demo intake (agent QR): `demo-intake/`.

Planned public host name: `bestlegalnet.com`. Current live host until cutover: `blc.salimheyaime.com`.
