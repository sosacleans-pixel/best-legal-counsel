# Best Legal Net

Static site for Best Legal Net, an advertising and information service for Utah car accidents. It is not a law firm and does not provide legal advice.

English homepage: `index.html`. Spanish homepage: `es/index.html`. Private intake: `intake/` and `intake/es/`. Demo intake (agent QR): `demo-intake/`. Unlisted agent application (not linked from the nav): `agents/apply/` and `agents/apply/es/`.

Planned public host name: `bestlegalnet.com`. Current live host until cutover: `blc.salimheyaime.com`.
